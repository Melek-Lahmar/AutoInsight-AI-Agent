# Synthetic sample data

Both files are fictional and exist only for development and demonstration.

- `students_performance.csv` intentionally contains two missing values, one duplicate row, a highly concentrated `Target` category, and an extreme `StudyHours` value. These exercise the quality rules.
- `sales_analysis.csv` is a comparatively clean dataset for chart and date-type demonstrations.

These records do not represent real students, customers, research findings, or commercial activity.
