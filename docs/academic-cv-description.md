# Academic CV project description

**AutoInsight AI Agent — Independent Full-Stack and Agentic AI Project**

Designed and implemented a privacy-aware CSV analytics platform with ASP.NET Core, C#, React, TypeScript, Microsoft Semantic Kernel, and Recharts. Built deterministic profiling, data-quality, statistical, visualization, and reporting services; exposed them as restricted AI-agent tools with observable multi-step function calling; and added automated backend, API, and frontend tests plus GitHub Actions CI. The architecture keeps uploaded rows local by default and separates credential-free deterministic analysis from optional model-backed interpretation.
